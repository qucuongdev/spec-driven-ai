# Spec template

Use .aidlc/specs/templates/intent/spec.md with the applicable stage outputs. For Markdown tracking, also copy .aidlc/specs/templates/MANUAL_TRACKER.md. Optionally run node .aidlc/tools/cli.js new TICKET to create a helper-managed record. Markdown decisions are not JSON receipts; see .aidlc/docs/USER_GUIDE.md for modes and migration.
